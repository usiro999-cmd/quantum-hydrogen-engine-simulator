# Q-Engine Lab

量子二準位オットーサイクルを使った、研究・学習向けの概念シミュレーターです。設計値を変更すると、励起確率、理想効率、1サイクルの仕事、理想出力をブラウザー上で再計算します。

> **重要:** このプロジェクトは実在する水素エンジンの設計・性能予測ツールではありません。準位差は抽象的な二準位モデルのパラメーターであり、水素原子の準位構造や実現可能な装置をモデル化していません。損失、デコヒーレンス、有限速度、制御エネルギーも含みません。結果は理想化された概算です。

## 起動方法

`index.html` をブラウザーで開きます。依存パッケージ、ビルド、サーバーは不要です。数値を変更するとシミュレーション結果とサイクル図が更新されます。

## モデル

高温・低温熱浴と平衡化した二準位系の励起確率を

`p = 1 / (1 + exp(ε / kBT))`

とし、理想仕事を `W = N(εh − εc)(ph − pc)`、理想熱効率を `η = 1 − εc / εh` として計算します。正の仕事を得るには、入力した温度と準位差がエンジン領域にある必要があります。定数にはボルツマン定数（eV/K）と電子ボルトのSI換算値を使います。

## テスト

Node.js がインストールされている環境で `npm test` を実行します。

## 水素原子シミュレーター v1.1

既存のエンジンとは独立した学習用アプリです。1s・2s・2p（m=0）・3d（m=0）の確率分布、エネルギー準位、バルマー系列と電気双極子遷移の模式アニメーションを表示します。エンジンモデルのエネルギーギャップとは対応しません。

Node.js 20.19以降または22.12以降で、以下を実行します。

```sh
cd hydrogen
npm install
npm run dev
```

表示されたローカルURLをブラウザーで開きます。ページ内のリンクから既存のエンジン画面にも移動できます。本番用は `npm run build` の後に `npm start` を実行してください。サーバーは `127.0.0.1` でのみ待ち受けます。

AI解説にはOpenAI APIキーと利用可能なAPI課金設定が必要です。サーバー起動前に環境変数 `OPENAI_API_KEY` を設定してください（例: `export OPENAI_API_KEY=...`）。キーをファイルに保存したりコミットしたりしないでください。`OPENAI_MODEL` でモデルを変更でき、省略時は `gpt-4.1-mini` を使います。AI以外の機能はキーなしでも使用できます。質問と選択中の軌道はOpenAIに送信され、API利用料金が発生する場合があります。AIの回答は誤る可能性があります。

点群は理想的な水素原子の波動関数に基づく確率分布の標本で、電子の軌跡ではありません。準位図・遷移は模式図で、微細構造や遷移強度を扱いません。`2s` と `1s` 間の単一光子電気双極子遷移は選択則で禁制のため、再生対象には含めていません。スペクトルの波長は水素のリュードベリ定数から計算した真空波長です。

水素原子アプリのテストは `cd hydrogen && npm test` で実行します。
